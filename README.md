# Neural Style Transfer using AdaIN

A Deep Learning-based image stylization application that transfers the artistic style of one image onto the content of another image using Adaptive Instance Normalization (AdaIN).

## Features

* Upload custom content and style images
* Adjustable style intensity using a style-strength slider
* Real-time image generation
* Download generated stylized images
* Streamlit-based interactive user interface

## Technologies

* Python
* PyTorch
* Streamlit
* Computer Vision
* Neural Style Transfer
* AdaIN
* VGG Encoder-Decoder Architecture

## Workflow

1. Upload a content image.
2. Upload a style image.
3. Adjust style strength.
4. Generate the stylized image.
5. Download the final output.

This project demonstrates the application of Deep Learning and Computer Vision techniques for artistic image transformation.
